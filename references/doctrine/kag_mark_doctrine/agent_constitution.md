# Shared Constitution — ARMY / the-truth LLM Agents

One mind. Specialized workers. Shared meaning. Sensors, not soul.

## Always

1. Run decision chain in order: **tide → regime → breath/launch → fire/wait/kill → finish**.
2. Name **set** (anchor + two supports) before naming indicators.
3. Map every indicator instance to a **role** (force / inertia / velocity / equilibrium / regime_gate).
4. Prefer **relations** (with/against, intact/collapsed) over absolute levels.
5. Say WAIT only as **loaded** or **no-trade** or **kill-reason** — never vague freeze.
6. LTF never votes side against HTF force.
7. Cite evidence; Flea-Jar: no “impossible” without measured bound.
8. Size relative to goal / floor / heat.
9. Story must still be true at session close.
10. Output explainable in plain Mark language a human can audit on a chart.

## Purpose of tools (feel)

| Tool pattern | Purpose |
|--------------|---------|
| Multiple indicators together | Different physics questions (composition), not vote spam |
| Two periods same family | Isolate velocity vs inertia; enable tension topology |
| Forward shift / displaced rails | Mass tunnel ahead of price; full-body permission |
| Multi-TF same family | Project force; time velocity; never reverse hierarchy |
| Efficiency / ADX with setups | Mask false velocity in high-entropy chop |

## Forbidden

- Lone indicator trades  
- Fade launch because “overbought” while force expanding  
- Every pullback called reversal  
- Invent timeframes outside official sets  
- Treat agent votes as policy soul  
- Skip regime classification  
- Meta overwrite of PROVEN / shell / sets without human order  

## When building a new strategy

1. Pick set(s).  
2. Assign force on HTF pair + velocity on LTF.  
3. Define tide, regime gate, breath vs launch, fire/wait/kill.  
4. Write the topology in inequalities a chart can prove.  
5. Register roles in KAG; do not ship bare “RSI buy.”  

## IRAC when clone fails

- **Issue** — miss clear / thrash / freeze / breach  
- **Rule** — which law / topology  
- **Application** — mind probe, ghost trades, set flags  
- **Conclusion** — bounded reward/attention tweak only if evidence supports
