DVMR FURTHER IMPROVEMENT (v2) — results summary
================================================

What we did beyond v1
---------------------
- 59 variants x 2 higher-TF combos (30m+4h, 1h+1d)
- Walk-forward OOS (4 time folds)
- GBPUSD confirmation
- Hybrid recipes combining winners

Diagnosis (unchanged root cause)
--------------------------------
Baseline dies on zero-cross exits (~2-3 bars). Fixing exits was step 1.
Step 2 (this round): tighter HTF gate, min hold before soft exit, optional ATR band.

GBPUSD honesty
--------------
Almost all strong EURUSD recipes LOSE on GBPUSD (PF 0.6-0.9).
Only marginal survivor of strict dual-symbol gate:
  1h+1d / HTF thr=0.45 / hard exits
  EURUSD +9.4% PF1.49 | GBPUSD -2.2% PF0.90

What did NOT help
-----------------
- BE + trailing stops
- Pullback entries
- HTF slope alone (too few trades)
- Faster n/m (3/12, 4/16) — destroyed edge
- Long-only (too few trades for reliability)

Recommended use
---------------
1) **EURUSD signal agent (promote as weak agent):** mode `v2`
   - Combo: 30m+4h (primary), optionally 1h+1d
   - HTF DVMR threshold 0.50
   - Soft exit DVMR ±0.5 only after >= 4 bars
   - No zero-cross panic exit
   - SL 1.5 ATR / TP 2.5 ATR / risk 1%

2) **If multi-pair required:** mode `v2_robust` on 1h+1d only
   - HTF thr 0.45, hard SL/TP only
   - Expect modest EURUSD edge, near-flat GBPUSD

3) **Do not promote:** 5m+30m under any variant
