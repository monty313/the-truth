## 1. Problem of *how to learn to learn*

**Definition (one paragraph):**

Learn-to-learn (L2L) is **not** “fit harder on yesterday’s candles.” It is the student’s ability to **abstract a failure into a reusable principle class**, correct **on its own trajectory** (not only on the expert’s offline path), and **keep baseline competence** while absorbing the class — so the *next* unseen day with the same structural error is handled without re-discovering the lesson from a date memo. Childhood is act-copy (BC). Adulthood is: classify path error → train structural heads / class heads under gates → KEEP only if pack survives and learn≠copy holds → remember the class for the next cycle.

**Finish line for “learned to learn” at this stage:** practice same **> 35**, breach **0**, learn≠copy **PASS**, and the fix is attributed to a **path class** (e.g. `anti_thrash` / `wait_loaded`), not to “trained on 2026-02-13.”
