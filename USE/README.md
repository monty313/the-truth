# USE — your daily buttons

**Only open this folder when you want to run something.**

Files start with `1_` `2_` `3_` so they stay in order.

| Button | What it does |
|--------|----------------|
| **1_prove.bat** | Score the champion (clear % / breach %) |
| **2_preflight.bat** | Check stack is ready |
| **3_self_heal.bat** | Diagnose + heal epoch |
| **4_train.bat** | GPU train climb |
| **5_open_goal.bat** | Open GOAL.md in notepad |

Double-click a `.bat`.  
A black window runs the command. Read the numbers at the end.
